The SQL table you ran is only HALF the setup. You also need to update the

WHY you see "apiKey and prompt are required"
--------------------------------------------
That message is from the OLD AI chat code on Supabase. It does not know about
password reset yet. The app sends action=passwordResetSendOtp but the live
server ignores it and asks for an AI api key + prompt instead.

FIX — Supabase Dashboard (no CLI needed)
----------------------------------------
1. Open https://supabase.com/dashboard
2. Open your project (gvufllqqxjnpicmkxzcg)
3. Left menu → Edge Functions
4. Click the function named: bright-handler
   (If you only see ngmy-ai-chat, open that one — it may be the same thing.)
5. Open the code editor for that function
6. On your PC, open this file in Notepad or Android Studio:

   C:\Users\appbu\StudioProjects\ngmy\supabase\functions\ngmy-ai-chat\index.ts

7. Select ALL (Ctrl+A), Copy (Ctrl+C)
8. In Supabase editor: Select ALL, Paste (Ctrl+V) to replace everything
9. Click Deploy (or Save / Deploy updates)
10. Wait until it says deployed successfully

10. Hard refresh https://ngmy.org/ and try Forgot password → Send code again

Optional — Resend email fallback
--------------------------------
If Supabase email OTP fails, the server can email codes via Resend.
In Supabase → Project Settings → Edge Functions → Secrets, add:
  RESEND_API_KEY = your key from resend.com
  RESEND_FROM_EMAIL = NGMY <noreply@ngmy.org>  (must be verified in Resend)

After deploy you should get either:
- A code email from Supabase, OR
- A code email from Resend (6-digit number)

NOT "apiKey and prompt are required" anymore.
