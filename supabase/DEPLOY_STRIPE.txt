────────────────────────────────────────────────────────────
STEP 1 — Create database table (Supabase SQL Editor)
────────────────────────────────────────────────────────────

Open: https://supabase.com/dashboard/project/gvufllqqxjnpicmkxzcg/sql/new

Paste and run the full contents of:
  supabase/ngmy_stripe_access_table.sql

────────────────────────────────────────────────────────────
STEP 2 — Deploy webhook Edge Function
────────────────────────────────────────────────────────────

From project folder (needs Supabase CLI logged in):

  supabase functions deploy ngmy-stripe-webhook --project-ref gvufllqqxjnpicmkxzcg --no-verify-jwt

Or upload supabase/functions/ngmy-stripe-webhook/index.ts in:
  Supabase Dashboard → Edge Functions → Create function → ngmy-stripe-webhook

IMPORTANT: Webhook must be deployed WITHOUT JWT verification
(Stripe does not send Supabase auth tokens).

────────────────────────────────────────────────────────────
STEP 3 — Add Supabase secrets
────────────────────────────────────────────────────────────

Supabase Dashboard → Project Settings → Edge Functions → Secrets

Add:
  STRIPE_SECRET_KEY     = sk_live_...   (Stripe → Developers → API keys → Secret key)
  STRIPE_WEBHOOK_SECRET = whsec_...     (from Step 4 after creating webhook)

SUPABASE_URL and SUPABASE_SERVICE_ROLE_KEY are auto-injected for Edge Functions.

────────────────────────────────────────────────────────────
STEP 4 — Create Stripe webhook
────────────────────────────────────────────────────────────

Stripe Dashboard → Developers → Webhooks → Add endpoint

Endpoint URL:
  https://gvufllqqxjnpicmkxzcg.supabase.co/functions/v1/ngmy-stripe-webhook

Events to send:
  checkout.session.completed

Copy the Signing secret (whsec_...) → paste into Supabase secret STRIPE_WEBHOOK_SECRET

────────────────────────────────────────────────────────────
HOW IT WORKS
────────────────────────────────────────────────────────────

User pays → Stripe sends webhook → Supabase saves access
         → App checks Supabase by email → unlocks feature

This works on phone, desktop, and any device — not just redirect URLs.

────────────────────────────────────────────────────────────
TROUBLESHOOTING
────────────────────────────────────────────────────────────

• Paid but still locked?
  - Check ngmy_stripe_access table for your email
  - Check Stripe webhook logs for failed deliveries
  - Edge Function logs in Supabase Dashboard

• Webhook 400 signature invalid?
  - STRIPE_WEBHOOK_SECRET must match the endpoint signing secret

• Webhook 422 unknown product?
  - Payment link checkout must pass client_reference_id (app does this automatically)

• Table missing error in app?
  - Run ngmy_stripe_access_table.sql in SQL Editor
